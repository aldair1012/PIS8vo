crear la base documental RAG local de Flowise. El dashboard y las APIs del
sistema siguen siendo la fuente de los datos actuales de cada parcela.

## Reglas de uso

- No usar una cifra de ESPAC como medición actual de una parcela.
- No mezclar recomendaciones de Sierra y Litoral sin comprobar la ubicación y el cultivo.
- Las dosis de insumos requieren análisis de suelo, etiqueta vigente y validación técnica.
- El RAG aporta conocimiento de referencia; no reemplaza clima, suelo ni simulaciones
  obtenidos por las APIs y los dashboards de ZeaSys.
