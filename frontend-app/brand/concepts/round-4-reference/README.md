# ZeaSys · referencia de mazorca · ronda 4

La referencia aportada muestra una mazorca vertical con elote visible, hileras de granos y dos hojas abiertas. Esta ronda retoma esa composición con geometría propia y proporciones simplificadas para probarla como marca.

- **Mazorca abierta:** conserva el gesto de dos hojas extendidas y una mazorca central.
- **Granos en hileras:** variante más compacta con semillas redondeadas y orden alterno.
- **Mazorca con Z:** incorpora la inicial de ZeaSys en el centro del elote.

Exploraciones en monocromo; no reemplazan aún los activos del sistema.
