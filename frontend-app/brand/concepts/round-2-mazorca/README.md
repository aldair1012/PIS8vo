# ZeaSys · dirección de mazorca · ronda 2

## Brief de esta iteración

La dirección anterior se sintió demasiado abstracta. Esta ronda hace explícito el cultivo de referencia —maíz— y explora tres tratamientos: mazorca con hojas, construcción geométrica por granos y mazorca con monograma Z. Se conservan los supuestos de público, valores y paleta documentados en `../round-1/README.md`.

Los conceptos siguen monocromos para evaluar silueta y reducción. Son exploraciones para elegir dirección; no reemplazan todavía los logos que usa el sistema.
